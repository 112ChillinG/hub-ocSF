# FieldWise 作业提交总览（W10–W15，按课程作业分块单独提交）

> 本目录把 FieldWise 项目按你最初给的 **W10–W15 课程作业**拆成 7 份**可独立运行**的代码提交。
> 每份都是**零依赖、自包含**的 `.py`：直接 `python3 Wxx_xxx.py` 即可跑通并打印结果，
> 内嵌示例数据，无需依赖主项目其它文件——可单独交作业。

> ⚠️ 数据说明：所有示例使用**自生成模拟数据**，非真实生产业绩，求职时务必如实标注「仿真基准」。

## 二、怎么运行 / 提交

```bash
cd 维修管理项目/作业提交
python3 W10_RAG.py
python3 W11_工具调用.py
python3 W12_多轮对话Agent.py      # ①
python3 W12_并行Supervisor.py     # ④
python3 W13_Harness_Skills.py     # ②
python3 W14_自进化评估.py         # ③
python3 W15_Graph_LLM.py
```

- **单独提交**：每份 `.py` 自包含，可单独复制提交，不依赖主项目。
- **如需打包成文件夹**：把对应 `.py` 单独放进一个文件夹即是该周作业。
- **git 提交（可选）**：若老师要求版本控制，可在本目录 `git init` 后每周一个 commit：
  `git add W10_RAG.py && git commit -m "W10 RAG 检索增强生成"`，逐周提交。
